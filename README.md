# Te Ao Hou

Independent whānau whenua services platform for Jackson Tutahi. Built with an authorised 360 Degrees-style design reference, without copying production data or modifying the source application.

## Status
The first implementation is a controlled development foundation. Court submission, legal approval, finance and production client intake must not be represented as available until their separate acceptance gates are satisfied.

## Architecture
Node.js, Express, PostgreSQL and a responsive royal-purple application shell. Private sessions, server-side roles, scoped case access and append-only audit records. The public source repository must never contain client records, credentials or uploaded documents.

## Source reuse
Reference: Eden-Software-NZ/whanau-collective. Reuse the fixed sidebar, responsive workspace, semantic design tokens, cards, forms, role checking and audit patterns. Do not copy the production database, credentials, client-specific business modules or branding. The new implementation is independently maintained.

## Scope
Whānau onboarding, guided whenua plans, succession preparation, trust and housing pathways, application catalogue, document evidence, whānau collaboration, professional referrals, messages, appointments, operations, source-controlled resources, and governance reporting.

See the implementation files and release gates before enabling production intake.
